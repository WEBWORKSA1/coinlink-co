Ethereum prioritizes security and decentralization, which limits how many transactions fit in each block. Layer 2s (L2s) scale it by doing most of the work elsewhere and using Ethereum as the final court of record. For users, that mostly means much lower fees.

What a rollup does

A rollup collects many transactions, executes them on its own network, and periodically posts compressed transaction data — and in some cases a proof — to Ethereum. Because many transactions share the cost of one Ethereum posting, each user pays a fraction. Since 2024, Ethereum has offered a dedicated, cheaper data space (“blobs”) for rollups, which pushed L2 fees down further.

ExamplesArbitrum, OP Mainnet, BasezkSync, Starknet, Scroll, Linea

Third-party bridges and exchanges can get you out of an optimistic rollup faster than the native 7 days, for a fee, using their own liquidity.

The trust assumptions

  • Sequencers — most L2s use a single operator to order transactions. If it goes down, the network can stall; if it censors, users may need slower escape routes.
  • Upgradeability — many L2 contracts can be upgraded by a security council or multisig. Shorter or no exit windows mean more trust in those signers.
  • Proof systems — some rollups don't yet have fully permissionless fraud proofs, or rely on complex, still-maturing proving code.

Independent researchers such as L2BEAT rate rollups by maturity stage (Stage 0, 1, 2) based on how much they still depend on trusted parties. Check the stage before parking significant funds. Find it in our analytics directory.

Using L2s safely

  1. Use official bridges or established bridge aggregators — reached through verified links. Fake bridges are a common scam.
  2. Add networks from trusted lists. Wrong RPC settings can show fake balances or send transactions to the wrong place.
  3. Check the network before sending. Exchanges and wallets must both support the same L2 for a deposit to arrive.
  4. Keep a little ETH on the L2 for gas — most rollups use ETH for fees.
  5. Same address, different networks. Your EVM address is the same on Ethereum and L2s, but balances are separate.

FAQ

Are L2s as secure as Ethereum?

They inherit important guarantees from Ethereum, but the degree depends on their design and maturity stage. Many still depend on operators and upgrade keys, so they are not yet fully equivalent.

What's the difference between an L2 and a sidechain?

A sidechain has its own independent security (its own validators). A rollup posts data or proofs to Ethereum so that users can, in principle, verify or exit using Ethereum itself.
