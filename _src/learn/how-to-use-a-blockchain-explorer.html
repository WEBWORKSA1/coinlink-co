A block explorer is a search engine for a blockchain. Paste a transaction ID, wallet address or token contract and it shows exactly what happened on-chain. It's the best way to settle “did my payment go through?”, check whether a token is the real one, or document a theft for a report.

Pick the right explorer

Each network has its own explorers. Bitcoin transactions won't appear on an Ethereum explorer, and a token on Base won't appear on the Ethereum mainnet explorer. Our verified explorers list maps networks to official explorers. Explorers never need your wallet connection or seed phrase for looking things up — a site that asks is not an explorer.

Looking up a transaction

  1. Copy the transaction hash (TxID) from your wallet or exchange withdrawal history.
  2. Paste it into the explorer's search bar.
  3. Read the key fields:
    • Status — success, failed or pending.
    • Block / confirmations — how many blocks have been added since. More confirmations mean more finality.
    • From / To — sender and recipient addresses. For token transfers, “To” may be the token contract; look at the token transfers section for the real recipient.
    • Value — native coin amount sent.
    • Fee — what was paid to miners or validators.

If a Bitcoin transaction is stuck as unconfirmed, a mempool explorer shows its fee rate compared with current rates. Some wallets let you speed it up with replace-by-fee.

Looking up an address

Paste any address to see its balance, full transaction history and token holdings. Explorers often add labels for known entities such as exchanges or flagged phishing addresses — a useful warning sign if you're about to send funds. Remember that addresses are public: anyone can see the history of an address you share.

Checking a token contract

Before buying an unfamiliar token, open its contract page:

  • Contract address — confirm it matches the one listed on the project's verified website or a major data aggregator. Fake tokens copy names and tickers.
  • Verified source code — a checkmark means the published code matches what's deployed. Unverified contracts are a red flag.
  • Holders — if a handful of wallets own most of the supply, a few sellers can crash the price.
  • Contract functions — owner-only powers such as minting or pausing transfers deserve scrutiny.
  • Official links — some explorers display the project's website and socials submitted by the team.

Reading token approvals

Many EVM explorers include a token-approval checker. Enter your address to see which contracts can spend your tokens and revoke unneeded ones. Learn more in token approvals explained.

Using explorers after a scam

Record the transaction hashes and the scammer's addresses. Following the funds forward often shows them moving to an exchange deposit address — information that helps law enforcement and the exchange act. Include these details in reports; see what to do if you've been scammed.

FAQ

My exchange says it sent the withdrawal, but my wallet shows nothing. What should I check?

Look up the TxID on the explorer for the network the exchange used. Confirm the destination address and network match your wallet. If it's confirmed to the right address, your wallet may need to be switched to that network or have the token added.

Can explorers be faked?

Yes — phishing sites sometimes imitate explorers to show fake confirmations. Use a bookmarked, verified explorer.
